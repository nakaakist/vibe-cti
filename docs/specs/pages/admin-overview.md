# Vibe CTI 管理画面 全体設計書

（作成日: 2025-08-16）

## 1. 概要

Vibe CTI の管理画面は、CTI システムの設定・運用・監視を行う Web ベースの管理インターフェースです。

### 1.1 目的

- SIP トランク接続の設定管理
- ソフトフォンの設定とユーザー管理
- IVR フローの作成・編集・管理
- 通話履歴の確認と統計分析
- システム全体の監視と運用

### 1.2 対象ユーザー

- **システム管理者（Admin）**: すべての機能へのアクセス権
- **スーパーバイザー（Supervisor）**: 通話履歴・統計・ユーザー管理へのアクセス権
- **エージェント（Agent）**: 自身の設定と通話履歴のみアクセス可

## 3. 共通コンポーネント

### 3.1 ヘッダー

- **左側**: Vibe CTI ロゴ、環境表示（本番/ステージング/開発）
- **中央**: 現在のページタイトル、パンくずリスト
- **右側**: 
  - 通知アイコン（未読数バッジ付き）
  - ユーザー名・ロール表示
  - プロフィール設定
  - ログアウトボタン

### 3.2 サイドナビゲーション

- **デザイン**: 折りたたみ可能な縦型メニュー
- **アイコン**: 各メニュー項目にアイコン表示
- **アクティブ表示**: 現在のページをハイライト
- **権限制御**: ユーザーロールに応じて表示項目を制御

### 3.3 メインコンテンツエリア

- **ページヘッダー**: タイトル、説明、アクションボタン
- **フィルター・検索**: 一覧画面では上部に配置
- **データテーブル**: ソート・ページネーション機能付き
- **フォーム**: バリデーション、自動保存機能

### 3.4 通知・アラート

- **トースト通知**: 画面右上に一時表示
- **モーダルダイアログ**: 重要な確認・警告
- **インライン通知**: フォーム内のエラー・成功メッセージ


### 4.2 タイポグラフィ

- **フォント**: Inter（欧文）、Noto Sans JP（日本語）
- **サイズ**:
  - h1: 32px (2rem)
  - h2: 24px (1.5rem)
  - h3: 20px (1.25rem)

  - small: 12px (0.75rem)

### 4.3 スペーシング

- 基本単位: 4px
- パディング: 8px, 12px, 16px, 24px, 32px

- **UIフレームワーク**: shadcn/ui + Tailwind CSS
- **アイコン**: Lucide React
- **チャート**: Recharts
- **テーブル**: TanStack Table
- **フォーム**: React Hook Form + Zod

## 5. レスポンシブデザイン

### 5.1 ブレークポイント

- **モバイル**: < 640px
- **タブレット**: 640px - 1024px
- **デスクトップ**: > 1024px

### 5.2 レイアウト対応

- **モバイル**: サイドナビをハンバーガーメニューに変更
- **タブレット**: サイドナビを折りたたみ可能に
- **デスクトップ**: フルレイアウト表示

## 6. アクセシビリティ

- **WCAG 2.1 Level AA** 準拠
- キーボードナビゲーション対応
- スクリーンリーダー対応（ARIA属性）
- 高コントラストモード対応
- フォーカス表示の明確化

## 7. パフォーマンス要件

- **初期表示**: 3秒以内（LCP）
- **操作応答**: 100ms以内（FID）
- **ページ遷移**: 1秒以内
- **データ取得**: 2秒以内（大量データは段階的読み込み）

## 8. セキュリティ要件

- **認証**: OIDC/JWT によるトークン認証
- **権限制御**: RBAC による機能制限
- **セッション管理**: 30分無操作でタイムアウト
- **監査ログ**: すべての設定変更を記録
- **HTTPS**: すべての通信を暗号化

## 9. 国際化（i18n）

- **対応言語**: 日本語（デフォルト）、英語
- **日時表示**: ユーザーのタイムゾーンに応じて表示
- **数値フォーマット**: ロケールに応じた表示
- **言語切り替え**: ヘッダーから即座に切り替え可能

## 10. エラーハンドリング

### 10.1 エラー表示

- **ネットワークエラー**: 再試行ボタン付きエラー画面
- **権限エラー**: アクセス拒否メッセージ
- **バリデーションエラー**: フィールド単位でインライン表示
- **システムエラー**: エラーコード付きメッセージ

### 10.2 エラー回復

- **自動リトライ**: ネットワークエラー時に3回まで
- **下書き保存**: フォーム入力中の自動保存
- **セッション復元**: 切断後の自動再接続

## 11. 技術スタック

### 11.1 フロントエンド

- **フレームワーク**: React 18 + TypeScript
- **ビルドツール**: Vite
- **状態管理**: Jotai
- **ルーティング**: React Router v6
- **API通信**: Axios + React Query
- **WebSocket**: Socket.io-client

### 11.2 開発ツール

- **コード品質**: Biome（フォーマット・Lint統合ツール）
- **テスト**: Vitest + React Testing Library
- **E2Eテスト**: Playwright
- **Storybook**: コンポーネントカタログ

## 12. デプロイメント

- **ホスティング**: Nginx（静的ファイル配信）

- **環境変数**: ビルド時に注入
