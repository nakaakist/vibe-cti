# WebRTCにおけるcoturn（TURN）サーバーの必要性

## 概要

Vibe CTIシステムにおいて、coturn（TURNサーバー）が必要な理由と、WebRTCの通信における役割について説明します。

## WebRTCの基本構成

### プロトコルの使い分け

```
制御系（シグナリング）: WebSocket (TCP)
  ブラウザ ←→ Go Backend ←→ Janus

メディア系（音声/映像）: UDP (RTP/RTCP)
  ブラウザ ←→ (TURN) ←→ Janus
```

## なぜTURNサーバーが必要か

### 1. NAT/ファイアウォール問題

#### 典型的な環境
- **家庭用ルーター**: ほぼ全てのユーザーがNAT配下
- **モバイル回線（4G/5G）**: キャリアグレードNAT（CGNAT）使用
- **公衆Wi-Fi**: 制限的なネットワーク設定
- **企業ネットワーク**: ファイアウォールによるUDPブロック

#### 問題の本質
```
[ブラウザ] <------ UDP双方向通信 ------> [Janus]
 (NAT内)                               (グローバルIP)
    ↑
    NATがブロック（外→内の新規UDP通信）
```

JanusがグローバルIPを持っていても、クライアント側のNAT/ファイアウォールが外部からの新規UDP接続をブロックするため、直接通信ができません。

### 2. WebRTCの特性

WebRTCはP2P（ピアツーピア）でメディアを直接送受信：
- **双方向のUDP通信**が必要
- NATは「内→外」の通信は許可するが、「外→内」は原則ブロック
- UDPはコネクションレスのため、NATでの状態追跡が困難

## TURNサーバーの役割

### リレーサーバーとしての動作

```
[ブラウザ] --> [TURN] --> [Janus]
    ↑            ↓          ↓
    └────────────┘←─────────┘
```

1. ブラウザがTURNサーバーに「外向き」接続を確立
2. TURNが中継役となってJanusとメディアをやり取り
3. NATから見ると全て「内→外」の通信なので通過可能

## なぜWebSocketではダメなのか

### プロトコルの違い

| 項目 | WebSocket (TCP) | WebRTC (UDP) |
|------|----------------|--------------|
| 信頼性 | パケット再送あり | パケット再送なし |
| 順序保証 | あり | なし |
| 遅延特性 | 累積する | 一定 |
| 用途 | 制御・シグナリング | リアルタイムメディア |

### リアルタイム音声におけるTCPの問題

#### パケットロス発生時の挙動
- **UDP**: 0.1秒分の音声が欠落 → そのまま続行
- **TCP**: 再送待ち → 0.5秒以上の遅延 → 会話が成立しない

#### 具体的な影響
- **遅延**: 100ms → 500ms以上に増加
- **音質**: 途切れ、エコー、ロボット声
- **帯域**: 3-5倍必要（再送・ヘッダーオーバーヘッド）

## coturnが不要になる条件

以下の**すべて**を満たす場合のみcoturn不要：

1. JanusサーバーがグローバルIPを持つ
2. すべてのクライアントが以下のいずれか：
   - グローバルIPを直接持つ
   - Full Cone NAT配下（非常に稀）
   - UDPポート10000-20000が開放済み

**現実的にはこれらの条件を満たすことは困難**

## システムにおけるcoturnの設定

### ポート構成
```
3478/UDP・TCP   : STUN
5349/TLS        : TURN over TLS
443/TCP         : TURN TCP フォールバック
```

### NAT通過戦略
1. **STUN**で直接接続を試行
2. 失敗時は**TURN**経由でリレー
3. UDP不可の場合は**TCP/443**にフォールバック

## まとめ

- **制御通信（WebSocket）**: NAT通過に問題なし
- **メディア通信（UDP）**: NAT通過にTURN必須
- **音声品質**: UDPでないとリアルタイム性が保証できない
- **coturn**: 安定した通話を実現するための必須コンポーネント

開発環境や同一LAN内でのPOCでは省略可能な場合もありますが、本番環境では必須となります。
