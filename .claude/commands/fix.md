# コードの自動修正

このコマンドは、フロントエンドとバックエンドの両方で自動修正可能な問題を修正します。

## 実行内容

### フロントエンド
- Biomeによるコードフォーマット
- Lint警告の自動修正
- import文の整理

### バックエンド
- gofmtによるコードフォーマット
- goimportsによるimport文の整理

## 実行手順

```bash
# フロントエンドの自動修正
echo "🔧 フロントエンドの自動修正を開始..."
cd frontend
npm run fix

# バックエンドの自動修正
echo "🔧 バックエンドの自動修正を開始..."
cd ../backend
make fmt
```

## 修正後の確認

自動修正後は、`/validate`コマンドを実行して、すべての検証が通ることを確認してください。

## 注意事項

- 自動修正はコードのフォーマットと簡単なLintエラーのみを修正します
- 型エラーやロジックエラーは手動で修正する必要があります
- 修正内容は必ずレビューしてください
